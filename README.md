# Лабораторная 2

Лабораторная работа по расчёту радиопокрытия сетей мобильной связи: бюджеты каналов UL/DL, модели распространения сигнала, радиусы сот и число базовых станций.

## Описание

Скрипт `l2.m` рассчитывает:

- бюджеты восходящего (UL) и нисходящего (DL) каналов;
- максимально допустимые потери радиосигнала `MAPL_UL` и `MAPL_DL`;
- чувствительность приёмников BS и UE;
- зависимости потерь от расстояния для трёх моделей: FSPM, UMiNLOS, COST 231 Hata;
- радиусы сот по UL и DL для макросот (Hata) и микро/фемтосот (UMiNLOS);
- площадь одной БС и необходимое число БС для заданной территории;
- сводную таблицу и график зависимостей.

# Лабораторная 1
Лабораторная работа по цифровой обработке сигналов в MATLAB: дискретизация по Котельникову, ДПФ, спектральный анализ и квантование аудиосигнала.

## Описание

Работа состоит из двух частей:

1. **Синтетический сигнал** (`l1.m`) — генерация синусоиды `y(t) = 5·sin(2π·10·t + π/7)`, дискретизация с частотой Котельникова `Fs = 20 Гц` и с запасом `Fs = 80 Гц`, ручное ДПФ, амплитудные спектры, оценка памяти, восстановление сигнала.
2. **Реальный аудиосигнал** (`l12.m`) — загрузка `Voice.wav`, обрезка тишины, ДПФ, оценка ширины спектра по уровню −3 дБ, прореживание в 10 раз, квантование 3–6 бит и сравнение спектров.

`OSMS.m` — черновой скрипт с базовыми операциями (`fft`, графики), оставлен для истории.
